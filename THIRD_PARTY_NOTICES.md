# Sources and dependency notices

The October 23 learning upgrade independently adapts ideas from [LearnHarness](https://github.com/amosblomqvist/learnharness) and [Mathua](https://github.com/chuma-beep/mathua). It uses contextual workbooks, source-linked prerequisite maps, and separate teaching and independent practice records. It keeps the learner's existing exam scope and target.

LearnHarness was inspected at `6cba9c8c5afe8a63f47ea4ebae6e91d8a205cebb`. Its code is AGPL-3.0. Mathua was inspected at `0a776f7b0412fbce33d5cbd18fabcaac852b5232`. Its own code is MIT, while its third-party content has separate notices and restrictions. This package copies none of their implementation, lessons, diagrams or artwork.

The linked video is [Agent Harness for Learning Things](https://www.youtube.com/watch?v=nfTDljFG2g0) by Eero Alvar. Public metadata and chapters were available. The spoken transcript was not recovered, so the implementation does not claim to cover every video demonstration.

Study Tool uses SolidJS, Vite, TypeScript, KaTeX, ts-fsrs, wa-sqlite and Inter. Dependency versions and declared licenses are retained in `package-lock.json`; installed dependencies retain their own license files. Review distribution notices for the final packaging format before publication. The repository's existing Saans trial fonts are excluded from this candidate.

The project license has not been selected. This preparation does not publish or grant rights to private course materials.
